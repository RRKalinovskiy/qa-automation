# Демо: проверка по сценарию «Карточка клиента»

Пример показывает, как требования превращаются в этапы и пункты проверки
Saby. Используйте его как образец для навыка `saby-checks`.

## Исходный сценарий

> В карточке клиента можно изменить ФИО и телефон. ФИО обязательно,
> телефон сохраняется в формате `+1 555 010 20 30`. Вкладка «Документы»
> показывает пустое состояние, если документов нет.

## Карта проверки

| Этап | Пункт | Приоритет |
|---|---|---|
| Карточка клиента: шапка | ЧЛ. Шапка: обязательное ФИО | P0 |
| Карточка клиента: шапка | ЧЛ. Шапка: сохранение телефона | P1 |
| Карточка клиента: документы | ЧЛ. Документы: пустой список | P2 |

## Как записать

1. `saby_check_get({ check: "<ссылка>" })`.
2. `saby_check_tree({ check: "<ссылка>", depth: 2 })` — выбрать
   `structureId` корневого этапа.
3. `saby_check_import_scenario({ ..., dryRun: true })` — показать план.
4. `saby_check_import_scenario({ ..., dryRun: false })` — записать.
5. `saby_check_verify({ ..., expected: { sections: [...] } })` — проверить.

## Ожидаемый результат

- 2 этапа, 3 пункта;
- у каждого пункта заполнены описание и плановое время;
- статус новых пунктов — «Не тестировался»;
- `saby_check_verify` возвращает `ok: true`.
