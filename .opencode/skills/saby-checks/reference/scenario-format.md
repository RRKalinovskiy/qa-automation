# Формат сценария для `saby_check_import_scenario`

## Схема

```ts
type Scenario = {
  sections: Section[];
};

type Section = {
  name: string;                 // название этапа
  description?: string;         // требования/контекст этапа
  plannedMinutes?: number;      // 0..6000
  points: Point[];
};

type Point = {
  name: string;                 // одна проверяемая цель
  description?: string;         // шаги + ожидаемый результат
  plannedMinutes?: number;      // 0..6000
  status?: string | number;     // по умолчанию «Не тестировался»
  assigneeId?: number;          // id сотрудника
};
```

Ограничения:

- `sections` — от 1 до 200 пунктов суммарно (настраивается `maxPoints`);
- названия этапов и пунктов уникальны в пределах родителя;
- пустые названия запрещены;
- статус по умолчанию — «Не тестировался»;
- `parentSectionId` — `structureId` существующего корневого этапа.

## Как формулировать пункты

Плохо:

> Проверить карточку клиента.

Хорошо:

> ЧЛ. Карточка клиента: сохранение телефона.
> Шаги: изменить телефон → сохранить → перезагрузить.
> Ожидаемый результат: телефон сохранён и отображается в формате +1 555 010 20 30.

Правила:

1. Один пункт — одна цель.
2. Позитивный, негативный и граничный кейсы — разные пункты.
3. В описании есть шаги и наблюдаемый результат.
4. Нет «проверить корректно» без критерия.
5. Нет реальных персональных данных.
6. Плановое время реалистично: 5–15 минут на пункт.

## Что вернёт импорт

```json
{
  "dryRun": false,
  "check": { "id": 632121183, "name": "Тест AI", "url": "..." },
  "totalSections": 2,
  "totalPoints": 3,
  "plan": [
    { "action": "createStage", "name": "Карточка клиента: шапка" },
    { "action": "createPoint", "section": "Карточка клиента: шапка", "name": "ЧЛ. Шапка: обязательные поля" }
  ],
  "warnings": [],
  "createdDocIds": [633434480, 633434483],
  "verification": { "ok": true, "missing": [] }
}
```

`createdDocIds` — id документов, созданных именно этим вызовом.
Их можно удалить через `saby_check_item_delete`, если пользователь
разрешил очистку.
